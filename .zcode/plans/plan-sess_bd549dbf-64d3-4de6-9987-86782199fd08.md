## Deslop Pass — Moderate Intensity (CSS-only)

**Constraints honored:** All content stays. Color palette stays (Uranian Blue / Outer Space / Payne's Gray / Air Superiority Blue). Layouts stay. All other pages untouched. Only `styles.css` + one cache-bust digit in `index.html`.

### What gets fixed (the AI-design slop)

**1. Kill decorative `::before` glows on every section**
Remove/neutralize the radial-gradient mesh overlays on `.problem-solution::before`, `.specialties::before`, `.about::before`, `.contact::before`, `.testimonials::before`, `.footer::before`, `.apps-showcase::before`. The body already has a fixed gradient surface — that's enough. Replace with nothing (or a single hairline top border where a section divider is genuinely needed).

**2. Flatten card surfaces (the triple-gradient card signature)**
Replace `linear-gradient(145deg, #ffffff, #f8fafc)` backgrounds on `.specialty-card`, `.testimonial-card`, `.practice-card`, `.ps-solution-box`, `.contact-form`, `.video-card-more-content` → solid `var(--background-white)` (#FAFBFD). One hairline border (`rgba(169,206,244,0.2)`), one tinted shadow. No gradient fills inside cards.

**3. Replace bouncy hover physics with calm lifts**
Swap `cubic-bezier(0.34, 1.56, 0.64, 1)` (bounce) → `cubic-bezier(0.16, 1, 0.3, 1)` (smooth). Remove all `scale()` from hover states. Reduce `translateY(-12px)` → `translateY(-4px)`. Applies to: `.btn:hover`, `.specialty-card:hover`, `.testimonial-card:hover`, `.practice-card:hover`, `.portfolio-item:hover`, `.blog-card:hover`, `.icon-container:hover`, `.ps-media:hover`, `.video-play-button:hover`.

**4. Tone down image zoom**
`.ps-scene-image` (1.06 → 1.03), `.specialty-image img` (1.08 → 1.03). Slower duration for smoothness.

**5. Fix form validation flashing (red/green on load)**
`.contact-form input:invalid` currently shows red `#ef4444` before the user types. Change to: neutral border by default; green/red only on `:focus` or after a `.touched` class. Safe — JS validates via `isValidEmail()`, not CSS pseudos.

**6. Remove sliding text on hover**
`.specialty-content h3:hover` does `translateX(6px)`, `.cta-text:hover` does `translateX(10px)`. Drop the translate — keep the color change only. Calm.

**7. Kill the neon outer glow**
`.video-play-button` `box-shadow: 0 4px 16px rgba(169,206,244,0.4)` expanding to `0.6` on hover = neon glow. Replace with a single soft tinted shadow (`0 2px 8px rgba(54,73,78,0.12)`), no hover expansion.

**8. Remove `will-change` spam from resting elements**
Strip `will-change: transform` from `.btn`, `.specialty-card`, `.zoom-image img`, and other non-animating defaults. Keep only on elements genuinely in motion.

**9. Calm the hero tagline pill + trust badges**
Reduce border weight and background opacity on `.hero-tagline`, `.trust-badge`. Less "badge-y," more refined.

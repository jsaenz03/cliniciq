# Reposition ClinicIQ: practices → practice nurses

## Strategy in one paragraph
The site's addressee changes from "your practice" (the clinic as buyer) to **"you, the practice nurse"** — while keeping "GP clinic / general practice" as secondary SEO language. The commercial angle is **self-serve first, team second**: nurses start free today, no practice sign-off (Pro is already $9.99–$19.99/mo per tool), with "prove it, then share it with your team" as the secondary thread that seeds the later admin/manager personas. The H1, nav and layout stay persona-neutral so the next persona pass is a copy swap, not a redesign.
